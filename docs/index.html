Features
Built for Real-World Accessibility
🔒

Privacy-First Architecture

Only skeleton keypoints are processed — never raw video frames. No data leaves the device. GDPR-compliant by design.

⚡

Real-Time on Snapdragon NPU

ONNX model runs via QNN Execution Provider on Hexagon NPU. Sub-50ms inference enables live conversation flow.

🎯

Confidence Gate

Below threshold, shows top-3 candidates for one-tap confirmation. Above threshold, auto-speaks the recognized sign.

👤

On-Device Personalization

New users enroll by signing each word 3-5 times. Frozen encoder + lightweight classifier head = quick few-shot adaptation.

🌐

Offline-First Design

Zero internet required after installation. Works in rural clinics, remote government offices, and areas with poor connectivity.

🏥

Service Counter Focus

UI designed for split-screen counter setups — one side for the signing user, one side for the service provider.

Technical Details
Pipeline Components
🤲

Keypoint Extraction

MediaPipe Hands (2×21 landmarks) + Pose (33 landmarks) = 150 features per frame at 30 FPS.

MediaPipe 1.0
🧠

Sign Recognizer

4-layer Transformer encoder with positional encoding and masked mean pooling. ~3.2M parameters.

PyTorch → ONNX
🎙️

Speech Recognition

Whisper-tiny for speech-to-text, running via ONNX Runtime. Supports Hindi and English.

Whisper ONNX
🔊

Text-to-Speech

Windows SAPI via pyttsx3 for speaking recognized signs. Configurable voice and speed.

pyttsx3 / SAPI

Getting Started
Run SetuSign
# Clone and setup
git clone https://github.com/setusign/setusign.git
cd setusign
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt

# Verify environment
python env/check_env.py

# Run the demo
python demo.py

# Train on INCLUDE-50 (optional)
python data/download_include50.py
python -m setusign.keypoints.extract --split all
python -m setusign.recognizer.train --model transformer
